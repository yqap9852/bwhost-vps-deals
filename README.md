### 只想找便宜、穩定的入門 VPS

選 **20G KVM**。

US$49.99/年的價格適合個人網站、測試環境、學習 Linux、輕量 API 或低流量 WordPress。1 GB 記憶體不算寬裕，安裝太多控制面板和服務後容易開始吃緊，因此不要把它當成大型網站主機。

### 需要多個網站或資料庫

可以看 **40G 或 80G KVM**。

2 GB 到 4 GB 記憶體比較適合同時跑網站、資料庫、反向代理和監控服務。80G KVM 的年付價格為 US$199.99，對長期運行的中小型專案來說，年付通常比每月支付 US$19.99 更划算。

普通 Basic VPS 的價格較低，但路線不一定適合中國方向流量。E-Commerce 提供更多機房和較高連線規格，官方也列出部分位置具備 CN2 GIA、CMIN2 和 China Unicom Premium 等連線。

### 服務不能經常中斷

考慮 **E-Commerce+SLA**。

它的價格明顯高於 Basic 和一般 E-Commerce，但如果是付款系統、企業內部服務、重要 API 或對外營運網站，99.99% SLA 的價值不應只用 CPU 和記憶體來比較。

### 必須部署在香港、日本或新加坡

Ultra 的優勢是地區明確、亞洲方向延遲較低，但價格也高很多。若你的應用只是普通網站，先確認是否真的需要地域鎖定；有時候洛杉磯 E-Commerce 已經足夠，沒必要為了「看起來更近」而多付數倍費用。
